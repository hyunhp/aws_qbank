@ AIB-C01 D1 T1.1 applied use-case
S: A retailer's leadership asks why its new demand-forecasting model, trained on three years of sales, badly misjudged demand for a product line launched last month. The data team confirms the model worked as designed. What is the most likely explanation to give leadership?
A: The model has no historical examples for the new product line, so its predictions for it are unreliable
B: The model needs a larger GPU instance to produce accurate forecasts for new product lines
C: Forecasting models only work for products that are sold in more than one region
D: The model should have been trained on fewer years of data so that it reflects only the most recent buying patterns
K: A
W: A model learns patterns from the examples it was trained on. A product launched last month has almost no history, so the model is extrapolating beyond its training data.
X: B=Compute size affects speed and cost, not what the model has learned. | C=Region count is not a requirement for forecasting. | D=Less history would weaken the patterns for existing products without fixing the gap for the new line.
T: Models are only as good as the examples they learned from; new situations with little data need extra care.

@ AIB-C01 D1 T1.1 advanced comparison
S: A bank's executive committee is choosing between two fraud models. Model X flags 95% of fraud but also flags many legitimate transactions. Model Y flags 70% of fraud with very few false alarms. Customer complaints about blocked cards are the board's top concern this year. How should the tradeoff be framed?
A: Model X has higher recall but lower precision; Model Y favors precision, which reduces wrongly blocked cards
B: Model X has higher precision because it catches more fraud, while Model Y has higher recall and fewer misses
C: Both models have the same overall accuracy, so the committee should decide based on licensing cost and vendor support alone
D: Model Y is overfitting because it flags fewer transactions, so its results cannot be trusted in production
K: A
W: Catching more of the real fraud is recall; being right when you raise a flag is precision. With complaints about blocked cards as the priority, Model Y's higher precision fits the goal, at the cost of missing more fraud.
X: B=The terms are reversed: catching more of the fraud is recall, not precision. | C=The models clearly differ in errors, and accuracy alone hides the business tradeoff. | D=Flagging fewer transactions reflects a threshold and precision choice, not overfitting.
T: Frame model choices in business terms: which error costs more, missed fraud or wrongly blocked customers.

@ AIB-C01 D1 T1.1 applied definition
S: A product manager hears engineers say a chatbot's model is 'at inference' and asks what that stage means for the monthly budget. Which explanation is accurate?
A: Inference is when the trained model answers real requests, so its cost grows with usage volume
B: Inference is the one-time training run, so its cost is fixed once the model has been built and deployed
C: Inference is the data labeling phase, so its cost ends before launch
D: Inference is the model evaluation step, so it runs only when the model changes
K: A
W: Training builds the model; inference is the model producing outputs for live requests. Inference cost scales with the number and size of requests, so it becomes an ongoing operating expense.
X: B=That describes training, which usually happens before launch or periodically. | C=Labeling prepares training data and is separate from serving requests. | D=Evaluation measures quality; it does not serve users.
T: Training is mostly an upfront investment; inference is an ongoing cost that rises with adoption.

@ AIB-C01 D1 T1.3 advanced troubleshooting
S: An HR assistant built on a foundation model confidently cites a 'Section 7.4 remote work stipend' that does not exist in the company handbook. Employees are starting to rely on it. Which explanation and remedy should leadership understand?
A: The model generated plausible but false content, and grounding answers in retrieved handbook text reduces this risk
B: The model was hacked, and the only remedy is to rotate all employee passwords

D: The model is too small; moving to a larger foundation model with more parameters will eliminate invented answers entirely

@ AIB-C01 D1 T1.3 applied comparison

A: RAG reads the current catalog at question time, while weekly fine-tuning adds retraining cost and still lags behind changes
B: Fine-tuning is the only way for a model to use company data, so RAG cannot answer catalog questions
C: RAG permanently updates the model's weights each week from the catalog, which makes it riskier and more expensive than fine-tuning
D: Both approaches are identical in cost and freshness, so the choice does not matter
K: A
W: RAG retrieves the relevant catalog entries when a question is asked, so answers reflect the latest data without retraining. Fine-tuning bakes knowledge into the model and must be repeated as data changes.
X: B=RAG is a common way to use company data without training. | C=RAG does not change model weights; fine-tuning does. | D=They differ substantially in cost, effort, and how current the answers are.
T: For frequently changing facts, retrieve at question time instead of retraining.

@ AIB-C01 D1 T1.1 applied definition
S: A board member asks why a model that scored 99% on the data it was trained on scored only 64% on new customer data. Which explanation is correct?
A: The model memorized its training data instead of learning patterns that generalize, which is overfitting
B: The model was underfitting, meaning it was too simple to learn the patterns in the training data
C: New customer data is always lower quality than training data, so any model will score far lower on it
D: The 99% score proves the model is correct and the new data is mislabeled
K: A
W: A large gap between training performance and performance on new data is the classic sign of overfitting: the model fit noise and specifics of the training set.
X: B=Underfitting shows poor results on training data too, not 99%. | C=Lower scores on new data are not automatic; a large gap signals a modeling problem. | D=High training accuracy says nothing about generalization.
T: Judge models on data they have not seen; a big train-versus-test gap means overfitting.
