@ AIB-C01 D1 T1.3 applied use-case
S: A legal team wants an assistant to summarize 400-page case files that exceed the model's context window. Which approach lets every section influence the summary?
A: Summarize sections separately, then combine those summaries into a final summary
B: Send only the first pages that fit in the context window and ignore the remaining pages
C: Ask the model to guess the contents of the missing pages based on the case title alone
D: Increase the temperature so the model can process more pages in a single request
K: A
W: Splitting long documents into sections and summarizing in stages (map-reduce or iterative refinement) lets all content contribute despite context limits.
X: B=Ignoring pages loses information. | C=Guessing invents content. | D=Temperature does not change the context window.
T: Handle long documents by summarizing in stages.

@ AIB-C01 D1 T1.2 advanced use-case
S: A telecom wants to predict network equipment failures from sensor readings and also generate plain-language repair notes for technicians. Which combination fits?
A: A predictive model on sensor data for failures, plus a generative model to draft the repair notes
B: A single image classification model that reads the sensor data and also writes the repair notes automatically
C: A translation model for the sensor data and a speech model for the technicians' repair notes
D: A recommendation model for failures and a sentiment model to write repair notes for technicians
K: A
W: Different tasks call for different AI types: predictive models for failure risk from sensor data, and generative models for readable notes.
X: B=Image classification does not fit sensor data or writing. | C=Translation and speech do not predict failures. | D=Recommendation and sentiment do not fit these tasks.
T: Combine AI types when a solution has different kinds of tasks.
