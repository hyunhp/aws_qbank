@ AIF-C01 D2 T2.1 applied definition
S: A developer notices that a foundation model's output changes each time the same prompt is sent. Which inference parameter most directly controls this randomness?
A: Temperature
B: Maximum tokens
C: Stop sequences
D: Context window size
K: A
W: Temperature scales how random token selection is; lower values make outputs more deterministic and repeatable.
X: B=Maximum tokens limits length, not randomness. | C=Stop sequences end generation at a marker. | D=The context window limits input size, not randomness.
T: Lower temperature for repeatable outputs; raise it for variety.
V: Amazon Bedrock

@ AIF-C01 D2 T2.1 advanced definition
S: A team wants the model to choose only from the most probable next tokens whose combined probability reaches 0.9. Which parameter implements this?
A: Top-p (nucleus sampling)
B: Top-k sampling
C: Temperature scaling
D: Maximum output token limit
K: A
W: Top-p samples from the smallest set of tokens whose cumulative probability reaches the threshold p.
X: B=Top-k uses a fixed count of tokens, not a probability mass. | C=Temperature reshapes the whole distribution rather than cutting it at a cumulative probability. | D=Maximum tokens limits response length.
T: Top-p = cumulative probability cutoff; top-k = fixed number of candidates.

@ AIF-C01 D2 T2.1 applied definition
S: A new team member asks why transformer-based language models handle long, complex sentences better than older sequence models. Which statement best describes the transformer architecture?
A: It uses self-attention to weigh how each token relates to every other token
B: It reads text one character at a time and forgets each character once it is read
C: It looks up the closest stored sentence from its training data to answer
D: It applies hand-written grammar rules defined for each supported language
K: A
W: Transformers use self-attention to model relationships between tokens across the whole sequence, which enables strong language understanding and generation.
X: B=Transformers consider the whole context through attention. | C=They generate from learned parameters, not lookups of stored sentences. | D=They learn from data, not hand-written grammar.
T: Self-attention is the core idea behind transformers.

@ AIF-C01 D2 T2.2 applied use-case

C: Models always refuse financial tasks because of built-in regulatory restrictions in every country and industry
D: Models need a year of training on each company's financial data before use
K: A
W: Foundation models generate probabilistic outputs and can make calculation mistakes, so exact computations belong in deterministic code or tools.

@ AIF-C01 D2 T2.1 applied use-case
S: A developer wants to understand why a long prompt is being cut off and why costs are higher than expected. Which concept explains both?

B: Epochs, since each training epoch raises the cost of every inference call
C: Parameters, since each prompt changes how many parameters the model has
