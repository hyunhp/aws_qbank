@ AIF-C01 D3 T3.1 applied use-case
S: A company must choose a foundation model for a customer chatbot that needs fast responses at high volume, with modest reasoning requirements. Which selection factor matters most?
A: Latency and cost per request for a model that meets the quality bar
B: The largest parameter count available, regardless of latency or cost
C: The number of languages the model's training data originally came from
D: Whether the model was released most recently by any model provider
K: A
W: For high-volume, latency-sensitive use with modest reasoning needs, a smaller, faster, cheaper model that meets quality is usually best.
X: B=Larger models add latency and cost without needed benefit. | C=Language coverage matters only if required by the use case. | D=Newness alone does not determine fit.
T: Choose the smallest model that meets quality, latency, and cost needs.

@ AIF-C01 D3 T3.2 applied use-case
S: A prompt asks a model to classify support tickets, but results are inconsistent. Which prompt technique most likely improves accuracy?
A: Add a few labeled examples of tickets and their categories to the prompt
B: Ask the model to be more confident and never express any uncertainty
C: Remove the list of categories so the model can invent the best labels
D: Write the prompt in capital letters so the model treats it as important
K: A
W: Few-shot prompting shows the model examples of the desired input-output mapping, improving consistency.
X: B=Confidence instructions do not improve accuracy. | C=Removing categories produces inconsistent labels. | D=Capitalization does not improve reasoning.
T: Few-shot examples improve consistency on classification tasks.

@ AIF-C01 D3 T3.2 advanced use-case
S: A model makes mistakes on multi-step math word problems. Which prompt technique is most likely to help?
A: Ask the model to reason step by step before giving its final answer
B: Ask the model to answer with a single number and no explanation at all
C: Ask the model to answer as quickly as possible to avoid overthinking
D: Ask the model to repeat the question three times before answering it
K: A
W: Chain-of-thought prompting encourages intermediate reasoning steps, which often improves accuracy on multi-step problems.
X: B=Suppressing reasoning tends to reduce accuracy on complex problems. | C=Speed instructions do not improve reasoning. | D=Repeating the question adds nothing.
T: Chain-of-thought prompting helps multi-step reasoning.
