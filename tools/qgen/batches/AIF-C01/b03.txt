# AIF-C01 batch 03: Domain 5 (security, compliance, and governance)
@ AIF-C01 D5 T5.1 applied use-case
S: A company wants its applications in a VPC to call Amazon Bedrock without traffic crossing the public internet. Which AWS feature fits?
A: An interface VPC endpoint using AWS PrivateLink
B: An internet gateway attached to the public subnet
C: A NAT gateway placed in each private application subnet
D: An S3 gateway endpoint added to the route tables
K: A
W: Interface VPC endpoints powered by PrivateLink provide private connectivity from a VPC to Amazon Bedrock.
X: B=An internet gateway routes traffic to the internet. | C=A NAT gateway still sends traffic over the internet. | D=An S3 gateway endpoint serves only S3 (and DynamoDB types), not Bedrock.
T: Private access to Bedrock from a VPC → PrivateLink interface endpoint.
V: AWS PrivateLink, Amazon Bedrock

@ AIF-C01 D5 T5.1 applied use-case
S: A company wants only its data science role to invoke specific Bedrock models. Which control implements this?
A: An IAM policy allowing InvokeModel on those model ARNs only
B: A security group rule on the Bedrock service's public endpoint
C: A bucket policy on the S3 bucket that stores the team's prompts
D: A CloudWatch alarm that triggers whenever a model is invoked
K: A
W: IAM identity policies scoped to specific model ARNs and actions enforce least-privilege access to Bedrock models.
X: B=Security groups do not control Bedrock API authorization. | C=Bucket policies govern S3 access, not model invocation. | D=Alarms notify but do not restrict access.
T: Control model access with least-privilege IAM policies.
V: AWS IAM, Amazon Bedrock

C: Store training data in a publicly readable bucket
D: Share IAM access keys among the development team
