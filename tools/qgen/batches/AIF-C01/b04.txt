@ AIF-C01 D1 T1.1 applied comparison
S: A retailer wants to group customers by purchasing behavior without predefined labels. Which learning type fits?
A: Unsupervised learning
B: Supervised learning
C: Reinforcement learning
D: Transfer learning only
K: A
W: Finding groups without labels is unsupervised learning, for example clustering.
X: B=Supervised learning needs labeled outcomes. | C=Reinforcement learning learns actions from rewards. | D=Transfer learning reuses a trained model; it does not by itself find groups.
T: No labels and grouping → unsupervised learning.

@ AIF-C01 D1 T1.1 applied definition

A: Reinforcement learning
B: Supervised learning
C: Unsupervised learning
D: Self-supervised learning
K: A
W: Learning actions through rewards and penalties from interaction with an environment is reinforcement learning.
X: B=Supervised learning uses labeled examples. | C=Unsupervised learning finds structure in unlabeled data. | D=Self-supervised learning creates labels from the data itself.

@ AIF-C01 D1 T1.1 advanced comparison
S: A model predicts house prices from features such as size and location. Which task type and metric fit best?
A: Regression, evaluated with RMSE
B: Classification, evaluated with recall
C: Clustering, evaluated with accuracy
D: Classification, evaluated with AUC
K: A
W: Predicting a continuous value is regression; RMSE measures the typical size of prediction errors.
X: B=Recall evaluates classification. | C=Clustering is unsupervised and accuracy does not apply directly. | D=AUC evaluates classifiers, not continuous predictions.
T: Continuous targets → regression metrics such as RMSE or MAE.

@ AIF-C01 D1 T1.1 applied use-case
S: A model achieves 99% accuracy on training data but 70% on new data. What is the likely issue?
A: Overfitting to the training data
B: Underfitting of the training data
C: Too little training time overall
D: A bias-free, well-balanced model
K: A
W: A large gap between training and new-data performance indicates the model memorized training specifics rather than general patterns.
X: B=Underfitting shows poor training performance too. | C=Insufficient training usually causes underfitting. | D=The gap shows a problem, not a well-balanced model.
T: High train, low test → overfitting.

@ AIF-C01 D1 T1.2 advanced use-case
S: A team is screening proposed projects for machine learning. In which situation is machine learning a poor fit for the business problem?
A: When the answer must follow a fixed, fully specified formula
B: When patterns are complex and hard to write as explicit rules
C: When large amounts of relevant historical data are available
D: When predictions improve decisions and some errors are tolerable
K: A
W: If a problem is fully defined by fixed rules and must be exact, deterministic code is simpler, cheaper, and more reliable than ML.
X: B=Complex patterns favor ML. | C=Available data favors ML. | D=Tolerable errors and decision support favor ML.
T: Use rules for exact, fully specified logic; use ML for complex patterns.

@ AIF-C01 D1 T1.1 advanced use-case
S: Which TWO statements about training data and inference are correct? (Select TWO)
A: Training builds the model from data; inference uses it to predict
B: Inference can be real-time or batch depending on the use case
C: Inference always retrains the model on each new request it gets
D: Training must happen every time a single prediction is needed
E: Batch inference is only possible for image classification tasks
K: A,B
W: Training learns parameters from data; inference applies the model, either in real time for immediate needs or in batch for large offline jobs.
X: C=Inference does not retrain the model. | D=Training is not needed per prediction. | E=Batch inference applies to many task types.
T: Training learns; inference predicts, in real time or batch.
