@ AIF-C01 D2 T2.1 applied definition

A: It predicts the most likely next token given all previous tokens
B: It retrieves the next sentence from a stored copy of the internet
C: It translates the prompt into code and then executes that code
D: It selects words randomly without considering the earlier text
K: A
W: LLMs generate text autoregressively, predicting the next token based on the preceding context.
X: B=Models do not store and retrieve the internet. | C=Generation is not code execution. | D=Selection depends on context, not pure randomness.
