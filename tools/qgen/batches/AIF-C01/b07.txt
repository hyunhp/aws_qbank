@ AIF-C01 D3 T3.1 advanced tradeoff

B: Fine-tuning always costs less than RAG for any amount of source data

A: Summarize or trim older turns before sending them
B: Send the entire conversation history every time

@ AIF-C01 D3 T3.2 applied definition
S: A prompt includes one worked example of the desired answer format before the actual question. Which technique is this?
A: One-shot prompting
B: Zero-shot prompting
C: Prompt chaining
D: Fine-tuning
K: A
W: Including a single example is one-shot prompting; zero-shot has no examples, few-shot has several.
X: B=Zero-shot has no examples. | C=Prompt chaining splits a task across multiple prompts. | D=Fine-tuning changes model weights.
T: Zero-shot = no examples; one-shot = one; few-shot = several.

@ AIF-C01 D3 T3.2 advanced use-case

A: Prompt chaining
B: Model distillation
C: Negative prompting
D: Data augmentation
K: A
W: Prompt chaining breaks a complex task into sequential prompts where each step's output feeds the next.
X: B=Distillation trains a smaller model from a larger one. | C=Negative prompting specifies what to avoid, mainly in image generation. | D=Data augmentation expands training data.
T: Break complex tasks into chained prompts.

@ AIF-C01 D3 T3.4 applied definition

A: BLEU
B: RMSE
C: Recall
D: MAPE
K: A
W: BLEU measures overlap between machine translations and reference translations.
