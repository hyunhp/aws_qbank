@ AIF-C01 D5 T5.2 applied use-case
S: For an AI compliance review, a company must show audit-ready evidence that its AWS resources continuously comply with its configuration rules, with a history of compliance changes. Which service helps automate this evidence collection?
A: Amazon CloudFront
B: Amazon Polly
C: AWS Batch
D: AWS Config
K: D
G: ## Continuous compliance evidence with AWS Config
AWS Config records the configuration of your AWS resources and keeps a timeline of every change. It evaluates those resources against **rules** that describe how they should be configured.
- **Managed rules** cover common checks, such as "S3 buckets must block public access" or "CloudTrail must be enabled"; **custom rules** cover your own requirements.
- A **conformance pack** groups many rules (and optional remediation actions) into one package that represents a control set, and can be deployed across an organization.
- For every resource and rule, Config stores compliant or noncompliant results over time, so the evidence is collected automatically instead of through screenshots and spreadsheets.
Example: a rule checks that the S3 bucket holding model training data is encrypted and not public; auditors can see that it was compliant every day of the review period.
Note: AWS Audit Manager also collects audit evidence, but it has been closed to new customers since April 30, 2026, and AWS points new users to AWS Config conformance packs.
W: AWS Config: it continuously records resource configurations, evaluates them against rules and conformance packs, and keeps the compliance history that serves as audit-ready evidence.
X: A=Amazon CloudFront: CloudFront is a content delivery network that caches and serves content at edge locations; it does not record or evaluate resource compliance.
B=Amazon Polly: Polly converts text into lifelike speech; it has no audit, configuration tracking or compliance function.
C=AWS Batch: Batch schedules and runs batch computing jobs on managed compute; it does not evaluate resources against rules or keep evidence.
T: Automated, continuous evidence that AWS resources follow your configuration rules comes from AWS Config and its conformance packs.
V: AWS Config
