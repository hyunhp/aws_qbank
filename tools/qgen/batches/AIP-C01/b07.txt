# AIP-C01 batch 07: Domain 4 (operational efficiency) and Domain 5 (testing, troubleshooting)
@ AIP-C01 D4 T4.1 applied use-case
S: A GenAI app's monthly bill is dominated by output tokens from verbose answers. Which change cuts cost with the least quality impact?
A: Set response length guidance in the prompt and cap max tokens appropriately
B: Switch every request to the largest available model for better efficiency
C: Remove the system prompt so the model has fewer instructions to process
D: Retry every request twice and keep the shorter of the two responses
K: A
W: Clear length guidance plus a sensible max tokens cap reduces output tokens without harming answer quality.
X: B=Larger models cost more per token. | C=Removing instructions harms quality and saves little. | D=Retries double cost.
T: Control output length to control cost.
V: Amazon Bedrock

@ AIP-C01 D4 T4.1 advanced use-case
S: Many users ask identical questions about a stable FAQ. Which approach reduces model invocations the most?
A: A semantic cache that returns stored answers for similar questions
B: A higher temperature so each answer is unique and more engaging
C: A larger context window so each request includes all past answers
D: Batch inference that queues every interactive question for tomorrow
K: A
W: Semantic caching serves answers for semantically similar questions without calling the model again.
X: B=Unique answers do not reduce calls. | C=Larger context increases cost. | D=Next-day answers do not suit interactive use.
T: Cache answers for repeated or similar questions.
