# ANS-C01 batch 01: Domain 1 (network design)
@ ANS-C01 D1 T1.1 applied use-case
S: A global application serves users over TCP and UDP and needs two static anycast IP addresses with automatic failover between Regional endpoints. Which service fits?
A: AWS Global Accelerator
B: Amazon CloudFront with origin groups
C: Route 53 latency-based routing records
D: An internet-facing Application Load Balancer
K: A
W: Global Accelerator provides static anycast IPs and routes TCP and UDP to healthy Regional endpoints over the AWS network.
X: B=CloudFront focuses on HTTP(S) and does not provide static anycast IPs for UDP. | C=DNS routing returns changing IPs and depends on TTLs. | D=An ALB is Regional and HTTP only.
T: Static anycast IPs for TCP/UDP → Global Accelerator.
V: AWS Global Accelerator

@ ANS-C01 D1 T1.1 advanced use-case
