# DEA-C01 batch 02: Domain 2 (data store management)
@ DEA-C01 D2 T2.1 applied use-case
S: Analysts need to run complex SQL joins and aggregations over terabytes of structured data with consistent, fast performance for dashboards. Which data store fits?
A: Amazon Redshift
B: Amazon DynamoDB tables with global secondary indexes
C: Amazon ElastiCache for Redis with sorted sets
D: Amazon S3 Glacier Flexible Retrieval archives
K: A
W: Redshift is a data warehouse optimized for complex analytical SQL at scale.
X: B=DynamoDB is not built for complex joins. | C=ElastiCache is an in-memory cache. | D=Glacier is archival storage.
T: Analytical SQL at scale → Redshift.
