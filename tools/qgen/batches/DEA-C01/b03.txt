@ DEA-C01 D3 T3.1 applied use-case
S: A data engineer wants to automate a recurring data preparation task in Python without managing servers, triggered daily. Which TWO components fit? (Select TWO)

B: EventBridge Scheduler to trigger it daily
C: An always-on EC2 instance with a cron job
