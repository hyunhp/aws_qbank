@ DEA-C01 D4 T4.1 applied use-case
S: A Glue job needs to read from one S3 bucket and write to another. How should it authenticate?
A: An IAM role assigned to the Glue job with scoped S3 permissions
B: An IAM user's access keys hard-coded in the Glue job script
C: The root user's credentials passed as job parameters
D: A public bucket policy so the job needs no credentials
K: A
W: Glue jobs assume an IAM role that provides temporary, scoped credentials.
X: B=Hard-coded keys leak. | C=Root credentials must never be used. | D=Public buckets expose data.
T: Data jobs authenticate with IAM roles.
