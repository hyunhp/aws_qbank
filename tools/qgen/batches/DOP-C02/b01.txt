# DOP-C02 batch 01: Domain 1 (SDLC automation)
@ DOP-C02 D1 T1.1 advanced use-case
S: A company has 40 microservices, each with its own repository. It wants a consistent CI/CD pipeline for every service without maintaining 40 hand-written pipeline definitions. Which approach fits?
A: Define a reusable pipeline template in IaC and instantiate it per service
B: Copy one existing pipeline manually in the console for every new service
C: Use a single pipeline that builds and deploys all 40 services on every commit
D: Let each team design its own pipeline without any shared standards at all
K: A
W: A parameterized pipeline template (for example, CloudFormation or CDK) gives every service a consistent pipeline that is easy to update centrally.
X: B=Manual copies drift. | C=One pipeline for all services couples releases and slows feedback. | D=No standards lead to inconsistency.
T: Standardize pipelines with reusable IaC templates.
V: AWS CodePipeline, AWS CloudFormation

@ DOP-C02 D1 T1.4 advanced use-case
