@ DOP-C02 D2 T2.1 applied use-case
S: A team wants to reuse a standard, versioned VPC definition across many CloudFormation stacks. Which feature fits?
A: CloudFormation modules or nested stacks
B: Copying the VPC code into every template by hand
C: Creating the VPC in the console and documenting it in a wiki
D: Using stack outputs only, without any shared template code at all

W: Modules and nested stacks package reusable, versioned template components.
X: B=Copies drift. | C=Console creation is not IaC. | D=Outputs share values, not definitions.
T: Reuse IaC components with modules or nested stacks.
