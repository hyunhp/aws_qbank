# DOP-C02 batch 03: Domain 4 (monitoring and logging)
@ DOP-C02 D4 T4.1 applied use-case
S: A company must collect application logs from hundreds of EC2 instances and containers into CloudWatch Logs with consistent configuration. Which approach fits?
A: Deploy the CloudWatch agent (or FireLens for containers) with centrally stored configuration
B: Have each application write its logs to local files that engineers read over SSH when they need them
C: Email log files from each instance to the operations mailbox every night
D: Store all logs on a single shared EBS volume attached to one instance
K: A
W: The CloudWatch agent and FireLens ship logs consistently, with configuration managed centrally.
X: B=Local files are not centralized. | C=Emailing logs is unreliable. | D=A single volume cannot be shared across instances.
T: Centralize log collection with agents and shared configuration.
V: Amazon CloudWatch Logs
