@ DOP-C02 D5 T5.1 applied use-case
S: A company wants a central place to receive and route events from many AWS services and SaaS partners to automated responders. Which service fits?
A: Amazon EventBridge event buses with rules
B: Amazon SQS FIFO queues for each service
C: Amazon S3 buckets that collect event files
D: AWS Batch job queues for each event type
K: A
W: EventBridge ingests events from AWS services and partners and routes them with rules.
X: B=Queues do not route by content. | C=Buckets store files, not route events. | D=Batch runs compute jobs.
T: Central event routing → EventBridge.
V: Amazon EventBridge

@ DOP-C02 D5 T5.1 advanced use-case
