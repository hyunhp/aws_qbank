# DOP-C02 batch 05: Domain 6 (security and compliance)
@ DOP-C02 D6 T6.1 applied use-case
S: A pipeline in a tooling account deploys into 20 workload accounts. The company wants no long-term credentials anywhere in this process. Which design fits?
A: The pipeline's service role assumes deployment roles in each account through STS
B: An IAM user in each workload account whose access keys are stored in the pipeline
C: The root user credentials of each account stored as encrypted pipeline variables
D: One shared IAM user across all accounts with keys rotated every six months
K: A
W: Cross-account role assumption provides temporary credentials without stored keys.
X: B=Stored access keys are long-term credentials. | C=Root credentials must never be used this way. | D=Shared users with rotated keys are still long-term credentials.
T: Use role assumption for cross-account automation.
V: AWS STS, AWS CodePipeline
