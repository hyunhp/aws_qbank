# DVA-C02 batch 01: Domain 1 (development with AWS services)
@ DVA-C02 D1 T1.2 applied use-case
S: A Lambda function processes messages from an SQS queue in batches of 10. When one message fails, the whole batch is retried, causing duplicate processing. Which change fixes this?
A: Enable ReportBatchItemFailures and return the IDs of only the failed messages
B: Reduce the batch size to 10,000 so failures are spread across more messages
C: Increase the function timeout to 15 minutes so every message has more time
D: Delete the queue's dead-letter queue so failed messages are dropped quickly
K: A
W: Partial batch responses let the function report only failed messages, so successful ones are not retried.
X: B=Larger batches increase the blast radius. | C=Timeouts do not stop whole-batch retries. | D=Removing the DLQ loses failed messages.
T: Use partial batch responses with SQS event sources.
V: AWS Lambda, Amazon SQS
