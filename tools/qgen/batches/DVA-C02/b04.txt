# DVA-C02 batch 04: Domain 4 (troubleshooting and optimization)
@ DVA-C02 D4 T4.1 applied troubleshooting
S: A Lambda function fails with 'Task timed out after 3.00 seconds' while calling an external API. What should be checked first?
A: The function timeout setting and the external API's response time
B: The function's reserved concurrency value configured in the console
C: The number of layers attached to the function package
D: The function's environment variable names and ordering
K: A
W: The default timeout is three seconds; slow external calls exceed it unless the timeout is increased or the call is optimized.
X: B=Concurrency does not cause timeouts. | C=Layer count is unrelated. | D=Variable names are unrelated.
T: Lambda timeouts → check timeout settings and downstream latency.
V: AWS Lambda

@ DVA-C02 D4 T4.1 applied troubleshooting

A: The integration exceeds API Gateway's integration timeout
B: The client is not sending an API key with each request
C: The API's CORS configuration blocks slow responses

K: A

@ DVA-C02 D4 T4.1 advanced troubleshooting
