# MLA-C01 batch 03: Domain 3 (deployment and orchestration)
@ MLA-C01 D3 T3.1 applied use-case
S: A model must return predictions within 100 ms for an interactive web application with steady traffic. Which deployment option fits?
A: A SageMaker real-time endpoint
B: SageMaker batch transform job
C: SageMaker asynchronous endpoint
D: A nightly scheduled processing job
K: A
W: Real-time endpoints serve low-latency, synchronous predictions.
X: B=Batch transform is offline. | C=Async endpoints queue requests. | D=Nightly jobs are offline.
T: Low-latency online predictions → real-time endpoints.
V: Amazon SageMaker AI
