# SAA-C03 batch 02: Domain 2 (resilient architectures)
@ SAA-C03 D2 T2.1 applied use-case
S: An order service and a shipping service are tightly coupled; when shipping is slow, orders fail. Which change decouples them?
A: Send order events to an SQS queue that the shipping service consumes
B: Increase the timeout of synchronous calls from orders to shipping
C: Run both services on the same EC2 instance to reduce network hops
D: Merge both services into one application with a shared database
K: A
W: A queue buffers work between services so a slow consumer does not cause producer failures.
X: B=Longer timeouts still tie orders to shipping's availability. | C=Co-locating adds a single point of failure. | D=Merging increases coupling.
T: Decouple services with queues.
V: Amazon SQS

@ SAA-C03 D2 T2.1 advanced use-case
S: One event from an order service must be delivered to billing, inventory, and analytics services, each processing at its own pace. Which pattern fits?
A: An SNS topic with an SQS queue subscribed for each service
B: One SQS queue polled by all three services at the same time
C: Direct HTTP calls from the order service to each service
D: A shared database table that all three services poll
K: A
W: SNS fan-out to per-service SQS queues delivers each event to every consumer with independent buffering.
X: B=One queue delivers each message to only one consumer. | C=Direct calls couple services. | D=Polling a table is inefficient and couples services.
T: Fan out events with SNS to SQS queues.
V: Amazon SNS, Amazon SQS

@ SAA-C03 D2 T2.2 applied use-case

@ SAA-C03 D2 T2.2 advanced tradeoff
S: A company compares pilot light and warm standby DR strategies. Which statement is correct?
A: Warm standby runs a scaled-down working copy, recovering faster than pilot light at higher cost
B: Pilot light runs full production capacity in both Regions at all times
C: Warm standby keeps only backups with no running resources in the second Region
D: Pilot light always recovers faster than warm standby at a higher cost
K: A
W: Warm standby keeps a running, scaled-down environment; pilot light keeps only core components, so it is cheaper but slower.
X: B=That describes active-active. | C=That describes backup and restore. | D=Pilot light is generally slower and cheaper.
T: Warm standby is faster and costlier than pilot light.
