@ SAA-C03 D3 T3.3 applied use-case
S: A product catalog changes rarely but is read millions of times per day from a relational database. Which approach improves performance most cost-effectively?
A: Cache catalog queries in ElastiCache using a lazy-loading pattern with a TTL
B: Scale the database vertically to the largest available instance class size
C: Add Multi-AZ so the standby instance can serve half of the catalog reads
D: Move the catalog into S3 Glacier and restore items when users request them
K: A
W: Caching rarely changing, frequently read data offloads the database and lowers latency.
X: B=Scaling up is costly and still hits the database for every read. | C=The standby does not serve reads. | D=Glacier retrieval is far too slow.
T: Cache hot, rarely changing data.
V: Amazon ElastiCache
