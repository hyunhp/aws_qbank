# SAP-C02 batch 01: Domain 3 (continuous improvement for existing solutions)
@ SAP-C02 D3 T3.1 advanced use-case
S: A company runs 400 EC2 instances across 30 accounts. Patching is done manually and often missed, causing audit findings. The company wants a consistent, auditable patching process with minimal operational overhead. Which solution meets these requirements?
A: Use Systems Manager Patch Manager with patch policies from Quick Setup across the organization, and report compliance centrally
B: Write a cron job on every instance that downloads and installs updates from the internet every night at midnight
C: Replace all instances with new ones launched from a fresh AMI every quarter and keep manual patching between refreshes
D: Ask each account owner to log in weekly and run updates, then email screenshots of results to the audit team
K: A
W: Patch policies configured through Quick Setup apply Patch Manager across accounts and Regions in an organization and provide centralized compliance reporting.
X: B=Per-instance cron jobs are unmanaged and not auditable centrally. | C=Quarterly refreshes leave long exposure windows. | D=Manual processes are error-prone and not auditable.
T: Organization-wide patching → SSM Patch Manager with patch policies.
V: AWS Systems Manager

@ SAP-C02 D3 T3.3 advanced troubleshooting
S: An Aurora MySQL cluster shows high CPU on the writer during business hours. Analysis shows most load comes from read queries issued by a reporting tool. What is the most effective improvement?
A: Direct the reporting tool to the cluster's reader endpoint and add Aurora Replicas as needed
B: Increase the writer's instance size and keep all queries on the writer endpoint
C: Enable Backtrack so the writer can rewind queries that take too long
D: Convert the cluster to a single-AZ deployment to reduce replication overhead
K: A
W: Routing reads to the reader endpoint offloads the writer, and adding replicas scales read capacity.
X: B=Scaling up the writer is costly and does not separate workloads. | C=Backtrack rewinds data, not queries. | D=Single-AZ reduces availability without addressing read load.
T: Offload reads to the reader endpoint.
