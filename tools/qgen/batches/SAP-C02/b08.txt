@ SAP-C02 D1 T1.1 advanced use-case
S: A company needs IPv6 connectivity for new workloads in many VPCs while keeping outbound-only internet access for private IPv6 subnets. Which component fits?
A: An egress-only internet gateway for IPv6 traffic
B: A NAT gateway configured with IPv6 addresses only
C: A standard internet gateway on private subnets
D: A virtual private gateway for all IPv6 egress
K: A
W: Egress-only internet gateways allow outbound IPv6 traffic while blocking inbound connections.
X: B=NAT gateways primarily serve IPv4 translation (NAT64 handles different needs). | C=A standard IGW route allows inbound IPv6. | D=A VGW connects to VPNs, not the internet.
T: Outbound-only IPv6 → egress-only internet gateway.
V: Amazon VPC

@ SAP-C02 D1 T1.3 applied use-case
S: A company's centralized logging pipeline in one account is critical for security. Which improvement increases its reliability?
A: Buffer log delivery with Firehose or Kinesis and store logs in replicated S3
B: Write the logs directly to a single EC2 instance's local disk in one Availability Zone of the account
C: Send logs by email from each account to the security operations mailbox
D: Keep logs only in each source account for as long as they are needed
K: A
W: Managed buffering and durable, replicated storage keep log delivery reliable when components fail.
X: B=A single instance's disk is a single point of failure. | C=Email is unreliable. | D=Local logs defeat centralization.
T: Make central logging durable and buffered.
V: Amazon Data Firehose, Amazon S3

@ SAP-C02 D1 T1.4 advanced use-case
S: A company acquires a business with its own AWS Organization and wants to bring its accounts under central governance. What is the correct approach?
A: Invite the accounts after they leave their current organization, then move them into governed OUs
B: Merge the two management accounts into a single account by using the Organizations console
C: Attach the other organization as an OU without removing any accounts first
D: Copy all resources manually into new accounts before deleting the old ones
K: A
W: Accounts must leave their existing organization before accepting an invitation; then they can be placed in OUs with guardrails.
X: B=Management accounts cannot be merged. | C=Organizations cannot be nested as OUs. | D=Manual copying is unnecessary for most migrations.
T: Move accounts between organizations by leaving and accepting invitations.
V: AWS Organizations

@ SAP-C02 D3 T3.2 advanced use-case
S: A company wants temporary, just-in-time elevated access for production changes with approvals and automatic expiry. Which approach fits?
A: Temporary elevated access in IAM Identity Center with approval workflows and time limits
B: Permanent administrator permissions for all engineers in every production account
C: A shared break-glass password that is emailed to the engineers whenever they need it
D: Creating IAM users for each change and deleting them later manually
K: A
W: Time-bound, approved elevation grants access only when needed and removes it automatically.
X: B=Permanent admin violates least privilege. | C=Shared passwords are insecure. | D=Manual user lifecycle is error-prone.
T: Use just-in-time, time-bound elevated access.
V: AWS IAM Identity Center

@ SAP-C02 D3 T3.4 applied use-case
S: An application's database connections fail during RDS Multi-AZ failover for several minutes because clients cache DNS. Which improvement fits?
A: Use RDS Proxy so connections fail over faster without client DNS dependence
B: Increase the database instance size so that future failovers finish more quickly
C: Disable Multi-AZ to avoid failover events in the future
D: Hard-code the primary instance IP address in the application
K: A
W: RDS Proxy maintains connections and reduces failover time for applications.
X: B=Size does not fix DNS caching. | C=Disabling Multi-AZ reduces availability. | D=Hard-coded IPs break on failover.
T: Speed failover for clients with RDS Proxy.
V: Amazon RDS Proxy
