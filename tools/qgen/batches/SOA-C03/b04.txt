# SOA-C03 batch 04: Domain 4 (security and compliance)
@ SOA-C03 D4 T4.1 applied use-case
S: A company wants continuous threat detection for its accounts, such as compromised credentials or crypto-mining, with no agents to manage. Which service fits?
A: Amazon GuardDuty
B: Amazon Inspector
C: Amazon Macie
D: AWS Artifact
K: A
W: GuardDuty analyzes CloudTrail, VPC Flow Logs, and DNS logs to detect threats without agents.
X: B=Inspector scans for software vulnerabilities. | C=Macie finds sensitive data in S3. | D=Artifact provides compliance documents.
T: Account threat detection → GuardDuty.
V: Amazon GuardDuty

@ SOA-C03 D4 T4.1 advanced use-case
S: Security wants findings from GuardDuty, Inspector, and Macie across 30 accounts in one place with security standard checks. Which approach fits?
A: Security Hub with a delegated administrator and cross-account aggregation
B: Log in to each of the 30 accounts separately and review each console
C: Export findings manually to spreadsheets and email them each week
D: Disable the services in member accounts to reduce total finding noise
K: A
W: Security Hub aggregates findings across accounts and Regions and runs security standard checks.
X: B=Per-account review does not scale. | C=Manual exports are slow and error-prone. | D=Disabling services removes protection.
T: Centralize security findings with Security Hub.
V: AWS Security Hub

@ SOA-C03 D4 T4.1 applied use-case
S: A company must prevent member accounts from disabling CloudTrail, even with administrator permissions. Which control fits?
A: A service control policy that denies StopLogging and DeleteTrail
B: An IAM policy attached to the developers group in each account
C: A CloudWatch alarm that notifies security when a trail stops logging
D: A tag on the trail indicating it must never be disabled by anyone
K: A
W: SCPs set maximum permissions for member accounts, so denied actions cannot be performed even by administrators.
X: B=Account administrators could change IAM policies. | C=Alarms detect but do not prevent. | D=Tags do not enforce anything.
T: Preventive guardrails across accounts → SCPs.
V: AWS Organizations

@ SOA-C03 D4 T4.1 advanced use-case
S: A company must continuously evaluate its resources against a set of compliance rules and deploy the same rules across all accounts. Which feature fits?
A: AWS Config conformance packs deployed across the organization
B: CloudFormation drift detection run manually every quarter
C: Trusted Advisor checks reviewed by each account's owner
D: CloudWatch dashboards showing resource counts per account
K: A
W: Conformance packs bundle Config rules and remediation and can be deployed organization-wide.
X: B=Drift detection covers stack templates only and is manual here. | C=Trusted Advisor is not a compliance framework. | D=Counts do not evaluate compliance.
T: Organization-wide compliance rules → Config conformance packs.
V: AWS Config

@ SOA-C03 D4 T4.2 applied use-case
S: All new EBS volumes in an account must be encrypted automatically. What is the simplest control?
A: Enable EBS encryption by default in each Region
B: Ask engineers to select encryption for each volume
C: Take encrypted snapshots of volumes every night
D: Use only instance store volumes for all instances
K: A
W: EBS encryption by default ensures every new volume is encrypted in that Region.
X: B=Manual selection is error-prone. | C=Snapshots do not encrypt existing volumes in place. | D=Instance store is not persistent storage.
T: Enforce EBS encryption with encryption by default.
V: Amazon EBS

@ SOA-C03 D4 T4.2 advanced use-case
S: An existing unencrypted RDS instance must be encrypted. What is the correct approach?
A: Snapshot it, copy the snapshot with encryption, and restore a new instance
B: Enable encryption directly on the running instance in the console
C: Create an encrypted read replica and promote it without any snapshot
D: Modify the instance class, which encrypts storage automatically
K: A
W: Encryption cannot be enabled on an existing unencrypted instance; copying a snapshot with encryption and restoring creates an encrypted instance.
X: B=Encryption cannot be turned on in place. | C=Read replicas of unencrypted instances cannot be encrypted. | D=Instance class changes do not encrypt storage.
T: Encrypt existing RDS via encrypted snapshot copy and restore.
V: Amazon RDS

@ SOA-C03 D4 T4.2 applied use-case
S: A company wants all S3 buckets in its account to reject public access, regardless of individual bucket policies. Which setting fits?
A: S3 Block Public Access at the account level
B: S3 Object Lock in governance mode per bucket
C: S3 Versioning on every existing bucket
D: S3 Transfer Acceleration for all buckets
K: A
W: Account-level Block Public Access overrides bucket settings that would allow public access.
X: B=Object Lock prevents deletion, not public access. | C=Versioning keeps old versions. | D=Transfer Acceleration speeds uploads.
T: Prevent public buckets account-wide with Block Public Access.
V: Amazon S3

@ SOA-C03 D4 T4.2 advanced use-case
S: A public website on an ALB needs protection from SQL injection and bad bots. Which service fits?
A: AWS WAF with managed rule groups on the ALB
B: A security group allowing traffic from all IPs
C: A network ACL with an explicit allow rule only
D: AWS Shield Standard with no other controls
K: A
W: AWS WAF inspects HTTP requests and blocks attacks such as SQL injection using managed rule groups, including bot control.
X: B=Security groups filter by port and source, not request content. | C=NACLs filter by IP and port. | D=Shield Standard protects against network DDoS, not SQL injection.
T: Layer 7 web attacks → AWS WAF.
V: AWS WAF

@ SOA-C03 D4 T4.2 applied use-case
S: Which TWO actions protect data in transit to an ALB-hosted application? (Select TWO)
A: Use an HTTPS listener with an ACM certificate
B: Redirect HTTP requests to HTTPS on the listener
C: Enable S3 versioning on the log bucket
D: Store the TLS private key in user data
E: Allow only port 80 in the security group
K: A,B
W: An HTTPS listener with an ACM certificate encrypts traffic, and redirecting HTTP to HTTPS enforces it.
X: C=Versioning protects objects, not transit. | D=Private keys must not be in user data. | E=Port 80 alone is unencrypted.
T: Enforce TLS at the load balancer.
V: AWS Certificate Manager, Elastic Load Balancing

@ SOA-C03 D4 T4.1 advanced use-case
S: A company needs to ensure that EC2 instances can only be launched with approved AMIs and required tags. Which TWO controls help? (Select TWO)
A: IAM policies with conditions on AMI IDs and request tags
B: Config rules that detect non-approved AMIs and missing tags
C: A shared administrator password for all engineers
D: Disabling CloudTrail to reduce the volume of logs
E: A dashboard that shows instance counts by Region
K: A,B
W: IAM conditions prevent non-compliant launches, and Config rules detect any that slip through.
X: C=Shared passwords weaken accountability. | D=Disabling CloudTrail removes auditing. | E=Counts do not enforce anything.
T: Combine preventive IAM conditions with detective Config rules.
V: AWS IAM, AWS Config
