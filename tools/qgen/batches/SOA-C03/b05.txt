# SOA-C03 batch 05: Domain 5 (networking and content delivery)
@ SOA-C03 D5 T5.1 applied use-case
S: Instances in a private subnet need to download updates from the internet but must not accept inbound connections. What is required?
A: A NAT gateway in a public subnet and a private route to it
B: An internet gateway attached directly to the private subnet
C: A VPC peering connection to another account's public VPC
D: An S3 gateway endpoint in the private subnet's route table
K: A
W: A NAT gateway in a public subnet lets private instances initiate outbound connections while blocking inbound ones.
X: B=Internet gateways attach to VPCs, and a route to one makes the subnet public. | C=Peering does not provide internet access. | D=Gateway endpoints only reach S3 or DynamoDB.
T: Private outbound internet → NAT gateway in a public subnet.
V: Amazon VPC

@ SOA-C03 D5 T5.1 advanced use-case
S: A company must connect 30 VPCs and an on-premises network with centralized routing. Which service fits?
A: AWS Transit Gateway
B: VPC peering in a full mesh
C: A NAT gateway in each VPC
D: An internet gateway per VPC
K: A
W: Transit Gateway acts as a hub for VPCs and on-premises connections, avoiding a complex peering mesh.
X: B=A full mesh of 30 VPCs is hard to manage and peering is non-transitive. | C=NAT gateways provide outbound internet access. | D=Internet gateways do not connect VPCs.
T: Many VPCs plus on-premises → Transit Gateway hub.
V: AWS Transit Gateway

@ SOA-C03 D5 T5.1 applied use-case
S: Private EC2 instances access S3 heavily through a NAT gateway, and data processing charges are high. Which change reduces cost?
A: Add an S3 gateway VPC endpoint to the private route tables
B: Move the instances to a public subnet with public IP addresses
C: Add a second NAT gateway in the same Availability Zone
D: Enable S3 Transfer Acceleration on the destination bucket
K: A
W: Gateway endpoints route S3 traffic privately with no NAT data processing charges.
X: B=Public subnets expose instances unnecessarily. | C=More NAT gateways add cost. | D=Transfer Acceleration adds cost and targets long-distance uploads.
T: S3 from private subnets → gateway endpoint instead of NAT.
V: Amazon VPC

@ SOA-C03 D5 T5.1 advanced use-case
S: Applications in a VPC must call Amazon SQS privately without internet access. Which option fits?
A: An interface VPC endpoint for SQS
B: A gateway VPC endpoint for SQS
C: An egress-only internet gateway
D: A Direct Connect public VIF only
K: A
W: Interface endpoints (PrivateLink) provide private access to services such as SQS; gateway endpoints exist only for S3 and DynamoDB.
X: B=Gateway endpoints support only S3 and DynamoDB. | C=Egress-only gateways are for IPv6 internet traffic. | D=A public VIF reaches public endpoints over Direct Connect, not privately from the VPC.
T: Private access to most AWS services → interface endpoints.
V: AWS PrivateLink, Amazon SQS

@ SOA-C03 D5 T5.2 applied use-case
S: A global audience experiences slow downloads of static assets from an S3 bucket in one Region. Which service improves performance?
A: Amazon CloudFront with the bucket as origin
B: S3 Cross-Region Replication to one Region
C: A larger EC2 instance in front of S3
D: Route 53 simple routing to the bucket
K: A
W: CloudFront caches content at edge locations close to users.
X: B=Replicating to one more Region still leaves many users far away. | C=An instance adds a bottleneck. | D=DNS routing alone does not cache content.
T: Global static content → CloudFront.
V: Amazon CloudFront

@ SOA-C03 D5 T5.2 advanced troubleshooting
S: After updating files in the S3 origin, users still see old content through CloudFront. The team needs the change visible now. What should they do?
A: Create a CloudFront invalidation for the changed paths
B: Delete and recreate the S3 bucket with the same name
C: Increase the default TTL on the cache behavior
D: Disable CloudFront logging for the distribution
K: A
W: Invalidations remove cached objects from edge locations so the next request fetches the new version.
X: B=Recreating the bucket is disruptive and unnecessary. | C=A longer TTL keeps old content longer. | D=Logging does not affect caching.
T: Refresh cached content with invalidations or versioned names.
V: Amazon CloudFront

@ SOA-C03 D5 T5.2 applied use-case

A: Latency-based routing
B: Weighted routing
C: Simple routing
D: Multivalue routing
K: A
W: Latency-based routing answers with the Region that offers the lowest latency for the user.

@ SOA-C03 D5 T5.2 applied use-case
S: A company needs the zone apex, example.com, to point to an Application Load Balancer. Which record type fits?
A: A Route 53 alias record
B: A CNAME record at the apex
C: An MX record for the ALB
D: A TXT record with the IP
K: A
W: Alias records can point the zone apex to AWS resources such as ALBs; CNAMEs are not allowed at the apex.
X: B=CNAMEs cannot be used at the zone apex. | C=MX records are for mail. | D=TXT records hold text and do not route traffic.
T: Apex to AWS resources → alias records.

@ SOA-C03 D5 T5.2 advanced use-case
S: A company wants S3 content served only through CloudFront, blocking direct access to the bucket. Which configuration fits?
A: Origin access control plus a bucket policy allowing only the distribution
B: Public read on the bucket with CloudFront logging turned on
C: A security group on the bucket that allows CloudFront IPs
D: S3 Transfer Acceleration enabled on the bucket's endpoint
K: A
W: OAC lets CloudFront sign requests to S3, and the bucket policy allows only that distribution.
X: B=Public read allows direct access. | C=S3 buckets do not use security groups. | D=Transfer Acceleration does not restrict access.
T: Restrict S3 to CloudFront with OAC and a bucket policy.
V: Amazon CloudFront, Amazon S3

@ SOA-C03 D5 T5.3 applied troubleshooting
S: An instance in a public subnet cannot be reached on port 443. The security group allows 443 inbound. What should be checked next?
A: The subnet's network ACL rules for inbound 443 and outbound ephemeral ports
B: The instance's IAM role permissions for Amazon S3 buckets in the account
C: The CloudTrail trail configuration for the Region where the instance runs
D: The S3 bucket policy for the application's static files and assets
K: A
W: NACLs are stateless; they must allow inbound 443 and outbound ephemeral ports for responses.
X: B=IAM roles do not affect network reachability. | C=CloudTrail does not affect traffic. | D=Bucket policies do not affect instance access.
T: Check NACLs (stateless) when security groups look correct.
V: Amazon VPC

@ SOA-C03 D5 T5.3 applied troubleshooting
S: Users report intermittent 504 errors from an ALB. Targets are healthy but some requests take longer than 60 seconds. What is the likely cause?
A: Requests exceed the ALB idle timeout before the target responds
B: The ALB's security group is missing an outbound rule to the internet
C: The Route 53 record for the ALB has a TTL that is too long
D: The target group uses HTTP instead of HTTPS for health checks
K: A
W: A 504 from an ALB indicates the target did not respond before the timeout; increasing the idle timeout or speeding up the backend helps.
X: B=Outbound internet rules do not cause target timeouts. | C=DNS TTL does not cause 504s. | D=Health check protocol does not cause timeouts on requests.
T: ALB 504 = target response exceeded the timeout.
V: Elastic Load Balancing
