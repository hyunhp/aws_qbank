# SOA-C03 batch 07: Domain 2 (reliability and business continuity), continued
@ SOA-C03 D2 T2.1 applied use-case
S: A queue-based worker fleet on EC2 should grow when messages pile up. Which metric is the best basis for scaling?
A: Backlog per instance derived from queue depth
B: Total number of instances in the account
C: Average disk space used by each worker
D: Number of CloudTrail events per minute
K: A
W: Scaling on backlog per instance (queue depth divided by instance count) matches capacity to pending work.
X: B=Instance count is not a demand signal. | C=Disk usage is unrelated to queue load. | D=CloudTrail events do not reflect workload.
T: Scale queue workers on backlog per instance.
V: Amazon SQS, Amazon EC2 Auto Scaling

@ SOA-C03 D2 T2.1 advanced use-case

A: Spot Instances with diversified instance types
B: On-Demand Instances in a single instance type
C: Dedicated Instances in one Availability Zone
D: Reserved Instances for a single instance size

X: B=On-Demand costs more. | C=Dedicated Instances cost more and do not reduce interruptions. | D=Reservations suit steady usage, not flexible batch.

@ SOA-C03 D2 T2.2 advanced use-case
S: A stateful web app loses user sessions when instances are replaced. Which change improves resilience?
A: Store session state externally in ElastiCache or DynamoDB
B: Enable sticky sessions permanently with no expiration
C: Increase the minimum size of the Auto Scaling group
D: Use larger instances so that fewer are ever replaced

@ SOA-C03 D2 T2.2 advanced use-case
S: Private subnets in three AZs route to a single NAT gateway in one AZ. What is the reliability concern?
A: If that AZ fails, the other AZs lose outbound internet access
B: NAT gateways cannot be used from more than one subnet at a time
C: NAT gateways must be recreated every day to keep them working
D: Private subnets cannot route to NAT gateways in other AZs at all
K: A
W: A NAT gateway is zonal; for resilience, deploy one per AZ with each AZ's subnets routing to its local gateway.

T: Deploy a NAT gateway per AZ for resilience.
