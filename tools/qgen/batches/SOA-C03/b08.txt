@ SOA-C03 D3 T3.1 advanced use-case
S: A CloudFormation template needs the latest Amazon Linux AMI ID in each Region without hard-coding IDs. Which approach fits?
A: A parameter of type SSM parameter pointing to the public AMI alias
B: A mapping table updated manually each month with AMI IDs
C: A hard-coded AMI ID copied from the console in one Region and reused in all Regions
D: A Lambda function that guesses the newest AMI by its name
K: A
W: CloudFormation can resolve public Systems Manager parameters for the latest AMI IDs in each Region.
X: B=Manual mappings go stale. | C=Hard-coded IDs are Region-specific and stale. | D=Guessing is unreliable.
T: Resolve current AMI IDs via SSM public parameters.
V: AWS CloudFormation, AWS Systems Manager

@ SOA-C03 D3 T3.1 applied use-case
S: A CloudFormation stack must keep its RDS database when the stack is deleted. Which attribute fits?
A: DeletionPolicy set to Retain or Snapshot
B: UpdateReplacePolicy set to Delete on the database
C: A stack output with the endpoint
D: A condition that is always false
K: A
W: DeletionPolicy controls what happens to a resource when the stack is deleted; Retain keeps it and Snapshot saves a final snapshot.
X: B=UpdateReplacePolicy governs replacement during updates, and Delete removes it. | C=Outputs do not protect resources. | D=A false condition would prevent creation.
T: Protect data on stack deletion with DeletionPolicy.
V: AWS CloudFormation

@ SOA-C03 D3 T3.1 advanced troubleshooting

B: The stack policy denied creation of the EC2 instance resource
C: The instance type is unavailable in every Availability Zone
D: The template's outputs section references a missing export
K: A
W: CreationPolicy waits for a success signal; if cfn-signal is not sent, the stack times out and fails.
X: B=Stack policies apply to updates, not creation. | C=Unavailable types fail immediately. | D=Missing exports fail differently and quickly.
T: CreationPolicy needs cfn-signal to report success.

@ SOA-C03 D3 T3.1 advanced use-case

A: Immutable deployment
B: All at once deployment
C: Rolling without batches
D: In-place single batch
K: A
